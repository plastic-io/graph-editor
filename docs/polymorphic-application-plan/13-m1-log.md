Three things follow from that one change — the same host reached twice is the same instance, so its nodes keep their data between calls; two hosts carrying the same graph are two instances that share nothing; and a graph reached through itself is a *deeper path*, so it is a new instance with its own everything. That is recursion, and the path length is the depth. Node code gets `instance` ({path, depth, state}) beside `state`, which still means the graph's. When a recursion stops is the graph's business; `linkedGraphDepth` (32) is the ceiling for one that does not, and it fails naming the path it took. |

| 2026-09-22 | PB-085 `subscriptions/listen` — a stream a client holds open | done, deployed, **verified on the dev stage** (spike S-3 passed) | A read tool answers what is true now; an agent that wants to know when that stops being true had one option, which was to ask again.
